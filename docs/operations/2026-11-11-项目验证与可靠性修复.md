## 验证环境

- 当前机器为 macOS ARM64；原 `node_modules` 来自 Windows，不能直接复用 esbuild 和 Rollup 原生依赖。
- NTFS 挂载不支持 npm 所需的 `chmod`，因此依赖按现有锁文件安装到本机 APFS 缓存目录，并将工作区 `node_modules` 指向该目录。
- 本机依赖目录：`~/Library/Caches/csgh-image-studio/node-runtime/node_modules`。此目录及工作区链接均不提交；Windows 开发机仍在本机执行 `npm ci`。
- Python 离线测试默认在 Windows 使用 `python`，其他平台使用 `python3`；仍可通过 `PYTHON` 指定解释器。
- Rust 工具链及构建缓存位于 `/tmp/csgh-cargo`、`/tmp/csgh-rustup`、`/tmp/csgh-rust-target`，不修改系统 PATH，不依赖 Windows 编译产物。
- 工作区已有的行尾差异保留，不作为本次业务改动提交。
- 测试发现器跳过隐藏文件，Git 忽略 macOS 在 NTFS 上生成的 `._*` 元数据，避免把 AppleDouble 文件误当测试入口。
