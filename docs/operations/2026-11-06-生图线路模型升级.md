## 发布方案

1. 更新现有模型断言，先验证旧配置不满足新要求，再修改配置。
2. 验证相关行为测试、前端构建和 Rust 线路映射测试。
3. 提交推送后，从已提交源码建立独立服务器发布目录，复用服务器构建缓存。
4. 通过 Caddy 本机管理接口检查 `127.0.0.1:8787` 的在途请求，等待空档后备份旧二进制和状态文件，原子替换并重启。
5. 核对运行进程与候选产物摘要、本机及公网健康和原线路暂停记录。

不覆盖服务器历史源码快照，不读取或复制生产密钥文件，不发布员工安装包。网关模式客户端无需重新安装；本地直连客户端需后续重新打包才会包含新配置。
