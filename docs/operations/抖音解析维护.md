# 抖音视频解析维护

## 2026-10-06 故障原因与修复设计

视频可在浏览器播放，但云端 yt-dlp 2026.08.19 返回 HTTP 403，并统一提示 Fresh cookies。
直接检查详情接口后确认：ArgusSecurityPlugin 先拒绝缺少 UIFID 的请求，再拒绝缺少 SecSDK 签名的请求。
这类响应不能直接等同于 Cookie 过期；更新 Cookie 或重复执行同一个旧请求无法修复请求协议。

采用 yt-dlp 官方插件扩展点，只替换 Douyin 详情请求，保留已有视频格式解析、下载地址和网关接口。
无需升级客户端或重新编译 Rust。相比修改 yt-dlp 安装包，插件便于独立备份、回滚及随项目部署；相比引入浏览器服务，无需新增浏览器进程和依赖。

实现位置：`scripts/video/yt_dlp_plugins/extractor/csgh_douyin.py`。

- 从 yt-dlp 当前 Cookie 容器读取 `UIFID`，缺失时兼容 `UIFID_TEMP`。
- 为固定抖音详情地址增加设备参数、时间戳与 `x-secsdk-web-signature`。
- 签名使用协议固定常量与标准库 MD5，不包含本项目服务密钥，也不是密码存储算法。
- 继续调用 yt-dlp 原有 `_parse_aweme_video_app`，保持结果格式兼容。
- 缺少设备 Cookie、网络失败和作品没有视频分别报中文错误，不在错误中暴露签名 URL。
- 单元测试使用假 Cookie 和固定签名向量，不访问真实凭据或网络。

协议资料：[yt-dlp 插件开发](https://github.com/yt-dlp/yt-dlp/wiki/Plugin-Development)、[上游问题 9667](https://github.com/yt-dlp/yt-dlp/issues/9667)、[SecSDK 请求协议参考](https://github.com/ucmao/media-parser/blob/main/docs/parsers/douyin.md)。

## Cookie 更新

当前服务读取 `DOUYIN_COOKIE_PATH` 指定文件，生产路径为 `/opt/csgh-gateway/secrets/抖音cookie.txt`。
支持浏览器 JSON 导出和 Netscape 格式。更新时备份旧文件、验证摘要，保持 `csgh:csgh` 所有者及 `0600` 权限。
网关每次解析都会读取并转换临时副本，因此替换 Cookie 不需要重启服务。
Cookie 和完整签名 URL 不能提交到 Git，也不能粘贴到公开日志或文档。

## 安装插件

在服务器项目目录执行：

```bash
sudo bash scripts/video/install-plugin.sh
```

安装位置：`/opt/csgh-gateway/bin/yt-dlp-plugins/csgh/yt_dlp_plugins/extractor/csgh_douyin.py`。
该目录位于生产 yt-dlp 程序旁，属于 yt-dlp 默认插件搜索目录；插件由 root 持有，服务只需读取。
仅使用 `--no-plugin-dirs` 或替换 yt-dlp 的实际执行位置时可能不再加载，调整部署后应重新验证。
常规 `build-and-install.sh` 与 `update.sh` 会自动安装插件；本次仅安装插件即可，不必执行完整网关更新。

## 验证与回滚

本地回归：`node tests/video/douyin-plugin.test.mjs`。
云端必须使用 `csgh` 身份和网关相同的 Python、yt-dlp、Cookie 转换方式验证：确认视频编号匹配、存在播放地址，并对视频地址做小范围读取，确认响应为 MP4。
不要只把 `/health` 正常或 Cookie 文件复制成功当作视频解析成功。

安装脚本会给已有插件保留带时间戳的 `.bak-...` 副本。
首次安装需要停用时，将目标文件改为下划线开头的文件名（如 `_csgh_douyin.py`），yt-dlp 会跳过该模块；升级回滚时将已确认的备份恢复为 `csgh_douyin.py`。
回滚不改变 Cookie，不需要重启网关，但旧解析器仍可能遇到此次 403。
