## 后续部署要点

现有 `/opt/csgh-image-studio` 是独立历史快照，不应强行与 GitHub `main` 合并。按已提交源码准备发布目录，在服务器复用既有构建缓存：

```bash
sudo -u csgh env CARGO_TARGET_DIR=/opt/csgh-image-studio/src-tauri/target CARGO_BUILD_JOBS=2 \
  /home/csgh/.cargo/bin/cargo build --locked \
  --manifest-path /opt/csgh-releases/<发布目录>/src-tauri/Cargo.toml \
  --release --bin backend-gateway --no-default-features --features gateway
```

构建成功后核对产物摘要，备份运行文件和暂停状态，再替换、重启并检查健康。暂停状态必须保持字典结构，恢复某条线路只移除该线路记录，保留其他记录及其人工保护来源。禁止把访问令牌写入远程地址或公开文档。
