## 维护规则

1. 新增重要模块、部署流程或发布流程时，优先在 `docs/` 下新增专项文档。
2. `AGENTS.md` 只保留短摘要和索引，不写详细实现。
3. 根目录不要继续新增业务文档；按类型放入 `docs/architecture/`、`docs/operations/`、`docs/reference/` 或 `docs/plans/`。
4. 文档中禁止写入真实密钥、数据库连接串、OSS AccessKey、完整签名 URL。
