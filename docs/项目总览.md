# 项目总览

本文档承接根目录 `AGENTS.md`，记录“呈尚策划美工生图系统 PRO”的当前项目事实。新接手开发、排障、部署或发布前，先读这里，再按末尾索引进入专项文档。

## 1. 项目定位

本项目是面向外卖运营团队的桌面生图工具。用户在 Windows 桌面端登录后，可以围绕店铺和商品批量生成、修改、归档运营图片，并在后台查看账号、历史和统计。

当前工作区包括：

| 工作区 | 用途 |
|---|---|
| 三件套设计 | 生成头像、店招、海报 |
| 制作 1 张设计图 | 单张产品主图 |
| 制作全店图 | 多产品批量全店图 |
| 制作套餐图 | 多产品合成套餐图 |
| 图片墙生成 | 美团图片墙素材 |
| P 门头 | 门头招牌文字替换 |
| 视频店招 | 外卖视频裁剪导出 |
| 修改图片 | 对头像、店招、海报、产品图等二次编辑 |
| 详情页生成 | 电商详情页展示图 |
| 品牌故事 | 店铺品牌文案和 5 张配图 |
| 数据分析 | 截图生成专业数据分析图 |
| 历史记录 | 查看和下载 OSS 历史图片 |
| 后台管理 | 账号、生图统计、网关监控、OSS 历史，管理员可见 |

## 4. 运行架构

```text
Windows Tauri 桌面端
  ├─ React/Vite 前端：登录、表单、状态、历史、后台 UI
  ├─ Tauri/Rust 本地命令：文件、图片、视频、更新安装、本地直连模式
  └─ Supabase Auth：登录态保存在客户端

生产网关模式
  桌面端 HTTPS 请求 https://gw.hbcsch.pw
    ↓ Bearer Supabase access_token
  公共 DNS A 记录（当前直连；未来可选 GA）
    ↓
  Caddy 443
    ↓ reverse_proxy
  backend-gateway 127.0.0.1:8787
    ├─ 校验 Supabase 登录态和账号状态
    ├─ 网关队列、账号并发限制、线路健康监测、自动重试
    ├─ 调用多条 image-2 上游线路
    ├─ 生成图压缩为可交付规格后归档到 OSS
    └─ 写入 Supabase 历史和统计

  新版桌面端取得网关返回的签名 URL
    └─ 直接从阿里云 OSS 下载生成结果，不经网关转发图片
```

本地直连模式仍保留：未配置 `VITE_BACKEND_GATEWAY_URL` 时，桌面端通过 Tauri/Rust 直接调用生图上游和 OSS。生产推荐网关模式，敏感密钥只在服务器。

## 5. 数据流

### 登录与权限

1. 前端用 Supabase Auth 登录。
2. `profiles` 表保存显示名、角色、启用状态、登录次数。
3. 管理员页面依赖 `role = admin` 和网关侧二次校验。
4. RLS 保护用户只能读取自己的历史，管理员可读全量。

### 生图与归档

1. 前端工作区收集店铺名、平台、产品图和 prompt。
2. 生产模式下请求网关 `/api/generate-image`。
3. 网关校验 Bearer token，进入 FIFO 队列。
4. 网关根据线路健康、尺寸支持、并发上限选择 image-2 线路。
5. 上游返回图片后，网关压缩为可交付规格并归档到 OSS。
6. 新版客户端显式请求 URL 交付，直接从 OSS 下载并在本地转回 Base64；旧版客户端继续收到内联 Base64。
7. 网关写入 `generation_logs`；触发器递增 `generation_totals`。
8. 前端展示结果，历史页从 Supabase 和 OSS URL 读取。

完整兼容协议、画质标准、异常回退和部署流程见 `docs/architecture/生图结果OSS直连分发方案.md`。

### 自动更新

1. 启动时前端读取 Supabase `app_update_config`。
2. 如果云端版本高于当前版本且 `force_update` 开启，则弹出强制更新。
3. Rust/Tauri 流式下载 OSS 安装包到本机缓存。
4. 启动安装程序并退出旧应用。

完整流程见 `docs/自动更新.md`。

## 8. 数据库结构

Supabase 主 schema 在 `supabase/schema.sql`，迁移在 `supabase/migrations/`。

| 表/视图 | 用途 |
|---|---|
| `profiles` | 用户档案、角色、登录次数、启用状态 |
| `generation_logs` | 每张成功归档图片的历史记录 |
| `generation_totals` | 每个用户永久累计生图数量 |
| `generation_monthly_totals` | 每个用户按上海自然月累计生图数量 |
| `login_logs` | 登录审计 |
| `daily_generation_stats` | 按 Asia/Shanghai 切日的每日统计视图 |
| `app_update_config` | 桌面软件强制更新配置 |

数据库启用 RLS。service role 只允许放在服务器或受控本地环境，不进入客户端安装包。

| 网关并发和状态目录 | 云端网关 | 服务器 `gateway.env` |
