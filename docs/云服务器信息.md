## 常用运维命令

```bash
# 登录当前生产服务器
ssh admin@156.225.23.248

# 进入服务器项目目录
cd /opt/csgh-image-studio

# 升级网关代码并重启（先检查工作树和发布内容）
sudo bash docs/cloud-gateway/update.sh

# 查看网关状态和日志
sudo systemctl status csgh-backend-gateway --no-pager -l
sudo journalctl -u csgh-backend-gateway -f

# 查看 Caddy 状态和日志
sudo systemctl status caddy --no-pager -l
sudo tail -f /var/log/caddy/gateway.log

# 服务器本机健康检查
curl http://127.0.0.1:8787/health

# 公网健康检查
curl https://gw.hbcsch.pw/health
```
